# Consolidation‑Horizon

Neutral Membrane for Altitude‑Separated Runtime & Geometry Integration

---

📘 Overview

Consolidation‑Horizon is the neutral membrane repository that sits between:

- Constellation‑Manifold‑Toolkit (A6–A8 geometric operators, scalar fields, invariants)  
- Fun‑Sphere‑Fantasy‑Engine (runtime, UI, glyph rendering, XR surfaces, emotional physics)

This repo exists to consolidate surfaced paths, bridge altitude layers, and prevent cross‑contamination between mathematical operator development and runtime visualization systems.

It is not a math repo.  
It is not a runtime repo.  
It is the horizon layer where both sides meet safely.

---

🎯 Purpose

Consolidation‑Horizon provides:

- altitude‑aligned developer notes  
- runtime bridge documents  
- invariant summaries  
- operator integration guidelines  
- contributor instructions  
- API specifications  
- projection rules  
- provenance‑safe documentation

It ensures:

- math stays in the Toolkit  
- runtime stays in Fantasy Engine  
- bridges stay here  

This preserves NDH altitude separation and prevents “math‑to‑oblivion” contamination of UI/runtime repos.

---

🧭 Altitude Classification

Consolidation‑Horizon spans:

- A6 — Conceptual Geometry (CSO fields, collapse surfaces, spectral geometry)  
- A7 — Invariant Layer (operator invariants, collapse‑surface invariants, state‑machine invariants)  
- A8 — Holonomy‑Runtime Operators (holonomy update, curvature evolution, runtime projection)  
- A9–A12 — Runtime Integration Layer (Fantasy Engine bridges, API specs, contributor guidance)

It does not contain:

- raw operator derivations (A6–A8 math lives in .tex inside Toolkit)  
- runtime code (Fantasy Engine runtime lives in its own repo)  

It contains only the membrane documents.
